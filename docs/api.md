## vLLM Engine Metrics

The vLLM server exports a set of Prometheus metrics that provide real-time insight into engine performance and resource utilization. These metrics are accessed via the `/metrics` endpoint of the vLLM server.

### Key Performance Indicators (KPIs)

| Metric Name | Type | Description |
|:-----------------------------------|:-----------------------------------|:---------------------------------------------------------------------------------------------------|
| `vllm:generation_tokens_total` | Counter | Total number of tokens generated by the model. Used to calculate **Throughput (Tokens/sec)**. |
| `vllm:prompt_tokens_total` | Counter | Total number of prompt tokens processed. |
| `vllm:gpu_cache_usage_perc` | Gauge | The percentage of the pre-allocated KV cache currently in use. High values indicate potential VRAM pressure. |
| `vllm:num_requests_running` | Gauge | The number of requests currently being processed by the engine. |
| `vllm:num_requests_swapped` | Gauge | The number of requests that have been swapped to CPU memory due to insufficient VRAM. |

### Usage in Grafana

To calculate real-time throughput in Grafana, use the `irate` function over a short window:

**Generation Throughput:**
`irate(vllm_generation_tokens_total[1m])`

**Prompt Throughput:**
`irate(vllm_prompt_tokens_total[1m])`
